## ✨ Overview

The **Automated Search Result Opening System** is a browser automation project developed using Python and Streamlit.

Instead of manually opening multiple websites for research, users can enter a search topic and instantly access relevant resources across different platforms.

This project demonstrates practical implementation of:

* Object-Oriented Programming (OOP)
* Browser Automation
* User Interface Development
* Python Application Deployment
* Software Design Principles

---

## 🎯 Problem Statement

When researching a topic, users often:

❌ Open multiple websites manually

❌ Repeat searches across platforms

❌ Waste time navigating between tabs

This project solves the problem by automatically generating and opening relevant search destinations with a single click.

## ⚡ Getting Started

### Clone Repository

```bash
git clone https://github.com/ShreyaJ-27/Automated_Search_Result_Opening_System.git
```

### Move into Project Directory

```bash
cd Automated_Search_Result_Opening_System
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Launch Application

```bash
streamlit run main.py
```
